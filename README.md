# ProCom

ProCom is a FastAPI-based product commerce platform API.

## Setup

Install the project dependencies with [uv](https://docs.astral.sh/uv/):

```powershell
uv sync
```

## Development

See the [Development Guide](docs/development.md) for setup details, development commands, formatting, and project conventions.

The API is available at `http://127.0.0.1:8000`.

The health endpoint is available at `GET /health/live`.
